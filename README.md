# MeowY Studios

> 用技术创造有趣的数字体验。

MeowY Studios 是一个面向开源工具、桌面软件、启动器与创意项目的开发工作室。
我们专注于构建简洁、稳定、可扩展的技术产品，并通过开源社区持续分享经验与代码。

---

## 我们在做什么

### 🚀 游戏启动器

- **VoxVer Launcher** — 现代化 Minecraft 启动器
  - 多版本管理与一键启动
  - Mod/Modpack 搜索与安装（CurseForge + Modrinth）
  - 实例系统与 P2P 分享
  - 深色/浅色主题 + 国际化支持
  - Electron + Vue 3 + TypeScript 构建

### 🎨 设计系统

- **Lumin UI/UX** — 玻璃态设计系统与组件库
  - OKLCH 色彩空间 + CSS 变量驱动
  - 暗色/亮色/跟随系统 三种主题模式
  - Double-Bezel / Button-in-Button / Magnetic Hover 设计模式
  - 纯 CSS 零依赖，框架无关
  - 无障碍支持 + 响应式适配

### 🛠️ 开发者工具

- **VoxVer Launcher Docs** — 项目文档站
  - 安装指南、使用说明、故障排除

### 🌐 Web 服务

- **Game Club Website Backend** — 游戏社团网站后端
  - Python 构建
